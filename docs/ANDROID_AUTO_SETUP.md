# Автонастройка из Android

TG Proxy Android может настроить Relay по SSH, если пользователь ввёл данные VPS.
Процесс сначала выполняет read-only audit и меняет сервер только после подтверждения плана.

## Данные

- SSH host или IP.
- SSH port, обычно `22`.
- SSH username, обычно `root`.
- SSH password или key, если это поддерживает версия Android-приложения.
- Публичный Relay host/domain, если он уже выбран.
- Публичный path, по умолчанию `/apiws`.
- Флаг HTTPS.

Если поле public host пустое и включен HTTPS, Android проверяет nginx, Caddy, Apache и certificates, чтобы найти домены-кандидаты.
Пользователь должен выбрать домен до продолжения установки.

## Существующий Relay

Если на VPS уже установлен совместимый Relay, Android должен предложить подключиться к нему или добавить новый token, а не переустанавливать сервер с нуля.

## Обновления сервера

Если Relay старее совместимой версии, Android должен предложить:

- **Обновить**, если пользователь ввёл SSH-данные и владеет VPS.
- **Пропустить**, если у пользователя только импортированное подключение или обновлением занимается владелец VPS.

Подсказка об устаревшей версии может появляться при запуске приложения, пока сервер не обновлён.

## Безопасность

Автонастройка должна сохранять backups изменяемых файлов: Relay config, systemd unit и reverse proxy snippets.
Перед reload нужно валидировать nginx, Caddy или Apache config и не менять чужие домены автоматически.
